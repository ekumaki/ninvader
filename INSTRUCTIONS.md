# INSTRUCTIONS.md

## 1. Project Overview

A browser‑based, fixed‑screen shooting game with a Japanese ninja theme. The prototype implements Stage 1 only, but the codebase must be modular to accommodate future stages and new player ships.

## 2. Goals for the AI Coding System

1. **Generate** a complete, self‑contained codebase that runs the Stage 1 prototype in modern browsers (Chrome / Edge / Firefox / Safari).
2. **Organise** the project according to the folder structure below, automatically creating any missing directories.
3. **Respect** the version‑control workflow: *no* commits, pushes or version bumps unless instructed by the user.

## 3. Folder Structure

```
cryptoninja-invader/
├─ public/
│  └─ index.html            # Game canvas & UI root
├─ assets/
│  └─ img/
│     ├─ player/            # player_A.png, shuriken_01.png, shuriken_special_01.png …
│     ├─ enemy/
│     ├─ boss/
│     ├─ bullet/
│     └─ ui/                # UI icons auto‑generated by AI
├─ src/
│  ├─ core/                 # game loop, state management
│  ├─ entities/             # player, enemy, boss, UFO classes
│  ├─ systems/              # collision, input, audio
│  ├─ assets.ts             # asset pre‑loader
│  └─ main.ts               # bootstrap
├─ package.json             # version starts at 0.1.0 (SemVer)
└─ README.md
```

The AI Coding System may use TypeScript + Vite (or another modern bundler) *or* a lightweight Vanilla JS setup. PixiJS / Phaser / pure Canvas are all acceptable.

## 4. Build & Run

```bash
# install deps
npm install

# launch dev server with hot reload
npm run dev

# build production bundle
npm run build
```

A local development server must open `http://localhost:5173` (or similar) so the user can verify behaviour before any push.

## 5. Game Requirements (Stage 1 Prototype)

* **Player Ship**: Type‑A only, sprite sheet `player_A.png` (4 views). Movement ← →, shoot (`Space` / on‑screen button).
* **Bullets**:

  * Normal: `shuriken_01.png`, speed S, damage 1.
  * Special: `shuriken_special_01.png`, charge ≥3 s, speed 2×, damage 3×, pierce all enemies.
* **Enemies**: 48 × 48px invaders, lateral march + descent.
* **UFO**: bonus target, spawns randomly at top.
* **Boss**: HP 10, throws 16 × 16 px rocks, slow lateral movement.
* **Scoring**: simple fixed points; high‑score stored in `localStorage` and shown on title and in‑game (top‑left).
* **Audio**: MP3 effects, max 8 simultaneous. No BGM.
* **Responsive UI**: on‑screen ← → + shoot buttons for mobile (bottom left / bottom right).
* **FPS target**: 60.

## 6. Version & Deployment Workflow

1. AI Coding System generates/updates code **locally only**.
2. User tests locally and, when satisfied, gives explicit instructions to:

   * bump `package.json` version (SemVer)
   * commit & push to `main` of [https://github.com/ekumaki/cryptoninja-invader](https://github.com/ekumaki/cryptoninja-invader)
3. GitHub Actions auto‑deploys to GitHub Pages (`ekumaki.github.io/cryptoninja-invader`).
