# ninvader 改修計画書

## 概要
現在のプロトタイプは1ステージのみのシンプルなスペースインベーダー風シューティングゲームです。この改修計画により、3ステージ、3プレーヤー、3ボスに拡張し、高品質で読みやすいコードベースを構築します。

## 改修スコープ
- ✅ 含まれるもの：コアゲームプレイ、UI/UX、アセット更新、データ永続化
- ❌ 除外されるもの：BGM、PWA/ServiceWorker、CI/CD、アクセシビリティ、国際化、最短時間記録

## 1. リファクタリング & プロジェクト骨格

### 技術スタック
- **言語**: TypeScript + Vite ビルド（プレーンESモジュールも許可）
- **コード品質**: ESLint（Airbnb規則）+ Prettier
- **設定ファイル**: プロジェクトルートに共有設定配置

### ディレクトリ構造
```
src/
  core/        // エンジンユーティリティ、ゲームループ、衝突判定、入力
  scenes/      // Title、Game、GameOver、Debug、Option
  entities/    // Player、Bullet、Enemy、Boss、UFO、FX
  ui/          // HUD、ボタン、タッチコントロール、セレクター
  assets/      // 画像・音声（PNG、MP3/OGG）
```

### モジュール境界
- グローバルシングルトンを避ける
- 各シーンが自身のエンティティを所有
- シーン遷移にはシンプルなスタック使用

## 3. UI/UX

### シーン設計
- **タイトル画面**: 左右ボタン付きカルーセルで3機体選択
- **オプション画面**: SFX音量スライダー、入力モード切替（タッチ/キーボード）、ハイスコアリセット（確認ダイアログ）
- **タッチコントロール**: 右下に移動・射撃ボタン、左下に必殺技ボタン
- **デバッグ画面**: URL`?debug`で開く、任意ステージ・ボス選択
- **ゲームオーバー**: 現在スコア・ハイスコア表示、リトライで死亡ステージから再開（スコアは0リセット）

## 4. データ永続化（localStorage）

### キー設定
- **キー**: `cnp_invader_stats`
- **データ構造**: 
```json
{ "ver": 1, "highScore": 0 }
```

### 更新ロジック
- ゲーム終了時：`score > highScore`なら更新
- レコードリセット：`localStorage.removeItem(key)`実行

## 5. アセット仕様

### 画像仕様
- **形式**: 透明PNG（約1024×1024）
- **プレーヤー**: 3機体 + 各必殺技弾・エフェクト
  - 咲夜：既存プレーヤーA画像流用
  - ネム、シャオラン：新規作成予定
- **ボス**: 3体 + 各弾丸
  - 鬼：既存ボスA画像流用（ステージ3で使用）
  - 弁天、孤白：新規作成予定
- **敵**: 既存敵A画像を色変更で3色展開
- **UFO**: 団子 → **ゴリラ**にリデザイン（未作成）

### 音声仕様
- **形式**: MP3/OGG
- **種類**: 最低8種類（プレーヤー弾、敵弾、ボス弾、必殺技、ヒット、爆発等）
- **準備状況**: 未準備（実装時にダミー音声使用）
